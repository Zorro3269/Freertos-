⌚ OV-Watch 核心功能总览
1. 系统与交互体验
流畅的图形界面：基于 LVGL v8.2 框架构建，底层搭载 FreeRTOS 实时操作系统。

智能页面路由：采用栈（Stack）数据结构管理 UI 界面切换，支持平滑、准确的“返回上一级”操作。

抬腕唤醒：结合 RTC 定时中断与 MPU6050 姿态检测，实现低功耗下的手势识别亮屏。

按键防误触：按键逻辑优化为“按下并松开”才触发响应，并支持长按 KEY1 键快捷关机。

2. 健康与运动监测
全天候计步：即使在 MCU 休眠模式下，MPU6050 传感器仍可独立运行，持续记录运动步数。

心率检测：搭载 EM7028 传感器，采用自研的简易 PPG 峰值检测算法，提供快速的心率读取（注：血氧功能已预留，待开发）。

3. 实用工具应用
全功能计算器：内置基于双栈逻辑（操作数栈与运算符栈）的科学计算器，完美支持加减乘除混合运算优先级及小数点计算。

系统设置与记忆：利用外部 EEPROM 实现数据持久化，断电后依然能保存用户偏好与配置数据。

4. 功耗管理与高级特性 (硬件/系统级)
三级功耗管理模式：

运行模式：全功能开启，工作电流约 70-80mA。

睡眠模式：MCU 进入 STOP 状态，切断未使用的串口 IO，仅保留计步与 RTC 工作，功耗极低（约 800+μA）。

关机模式：TPS63020 停止 3V3 供电，仅依靠 Vbat 维持 RTC 运行，实现极限省电。

动态蓝牙控制：硬件级蓝牙使能电路，支持在不需要无线连接时彻底关闭蓝牙模块以节省电量。

无线 OTA 升级：系统架构分离了 Bootloader 与 APP，支持通过 KT6368A 蓝牙模块的 SPP 协议进行 IAP 无线固件升级，摆脱烧录线束缚。
